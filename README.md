<h2>⚙️ RUN IT LOCALLY</h2>

```bash
# 1️⃣ Clone the repository
git clone https://github.com/Yashvant203/Yashvant-Portfolio.git

# 2️⃣ Navigate to project directory
cd Yashvant-portfolio

# 3️⃣ Install dependencies
npm install

# 4️⃣ Run development server
npm start or npm run dev
```

Now open [http://localhost:3000](http://localhost:3000) in your browser 🚀

<h2>🌐 DEPLOYMENT</h2>

This site is deployed on Netlify, which automatically rebuilds and updates whenever you push changes.

To redeploy:
```bash
git add .
git commit -m "update"
git push origin main
```


Netlify handles everything else.
